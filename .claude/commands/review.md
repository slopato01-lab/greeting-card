Проверь: **$ARGUMENTS**

Если аргумента нет — проверяй незакоммиченные изменения и коммиты
текущей ветки относительно `main`.

Ничего не исправляй молча. Сначала список находок, потом спроси,
что чинить.

## Что смотреть

**Соответствие документам**
- Цвета, размеры, радиусы, тени — только переменные из `docs/DESIGN.md`.
  Любое значение в явном виде — находка.
- Каждая видимая пользователю строка есть в словаре `docs/PRODUCT.md`.
  Строка в коде — находка.
- Отступление от `docs/DESIGN.md` без правки самого документа — находка.

**Вёрстка**
- Мобильный первым, десктоп от 1280px, 768–1279 не забыт.
- Абсолютные координаты из эталонов не утащены в продакшн.
- Фиксированные высоты стали минимальными.
- Обводки только 1px и 2px.
- Область нажатия минимум 44×44.
- Карусели прокручиваются, последняя карточка не липнет к краю.
- Есть состояния: наведение, нажатие, фокус, выключено, загрузка,
  ошибка, пусто.
- `prefers-reduced-motion: reduce` учтён.
- Клавиатурная навигация, видимый фокус, контраст ≥ 4.5:1.

**Код**
- TypeScript strict: ни одного `any`, ни одного `!` для подавления типа.
- Валидация входных данных на границе каждого API-роута.
- Новых зависимостей нет. Появилась — находка, даже полезная.
- Подписки снимаются по `AbortSignal`, таймеры и rAF убраны.
- `Math.random()` в игровом коде — находка.

**Данные и деньги**
- Соответствующий пункт `docs/SECURITY.md` соблюдён.
- Секретов в коде нет, ключи ИИ и платёжки только с сервера.
- Вебхук идемпотентен, открытка создаётся по вебхуку, не по возврату.
- В логах нет содержимого сообщений и URL фотографий.

**Ассеты**
- Ссылок на `figma.com` в продакшн-коде нет.
