# Дизайн-система «Открыточка»

Источник правды по визуалу.

С 08.10.2026 **стиль и раскладка главной** взяты из
`design/главная greetinh-cards.jpg` (чужой макет, только десктоп,
564px в ширину — размеры сняты на глаз и пересчитаны на 1920).
Стиль действует на весь сайт. Смысл и тексты — наши, из словаря.

Кегли и раскладка внутренних страниц изначально из макетов Figma
(`324:246`, `341:607`, эталоны `design/desktop.html` и
`design/mobile.html`). **Цвет, шрифты и обводки в этих эталонах
устарели** — сверять с ними можно только порядок блоков.

Предыдущий стиль (светлый монохром из `design/главная.jpg`) заменён
целиком; файл макета оставлен для истории.

Если задача требует отступить от документа — сначала меняется документ.

## Характер

С 08.10.2026 (поздний вечер) сайт **светлый**: белая основа, тёмный
текст. Первый экран главной — по `design/главный экран.jpg`, подвал —
по `design/футер.jpg` (оба чужие макеты, взята структура). Решение
пользователя: «шрифты оставляй наши, цвета сохрани наши, но
с адаптивом под белый бэкграунд». Поэтому шрифты, золото и геометрия
прежние, а тёмная основа `#141414` стала цветом текста.

Скруглённые карточки на ступень темнее основы, тонкие обводки 1px,
пилюли с текстом капсом, огромные широкие заголовки, золотой акцент,
рукописные подписи со стрелками в герое.

Ничего полупрозрачного, никаких размытий, градиентов и теней.
Единственное исключение — 0.7 с анимации сборки открытки (утверждено
08.10.2026), в покое всё непрозрачное. Белая открытка на белом фоне
отделяется обводкой 1px `--line`, а не тенью.

**Золото `#ecd18a` — единственный акцент, и только заливкой.** Текст
на нём тёмный `--ink`. Заливка золотом у:
- главной кнопки и плашки-бейджа героя
- золотой карточки (этапы на главной и на /how)
- меток повода на карточках шаблонов, выделенного слова в заголовке FAQ
- кружков-точек, кнопки музыки во включённом состоянии

Золото **текстом, значком или линией** на светлом не читается (1.4:1),
поэтому там `--gold-deep #7d6219`: знак в логотипе, галочки, маркеры,
«солнце», промокод, прогресс, обводка выбранной игры и шаблона.

Второе по важности действие — тёмная пилюля `--ink` со светлым
текстом (`Button tone="dark"`). Выбранная пилюля — тоже тёмная.

## Шрифты

Оба с полной кириллицей и свободной лицензией (OFL) — проверено.

```css
--font-display: 'Unbounded';  /* 400, 500, 600 */
--font-ui:      'Inter';      /* 300, 400, 500 */
--font-hand:    'Caveat';     /* 500 */
```

**Caveat** (с 08.10.2026) — только рукописные подписи со стрелками
в герое, как в `design/главный экран.jpg`. Декор: подписи скрыты от
скринридера, кегль `--text-hand` 22 / 28.

**Unbounded** — заголовки, логотип, название на карточке шаблона,
крупные номера. Начертание Medium, трекинг −2% (`tracking-tight`).
Выбран 08.10.2026 вместо Montserrat Alternates: в макете широкий
гротеск, из свободных с кириллицей Unbounded к нему ближе всего.

**Inter** — всё остальное. Он же по умолчанию на `body`.

Капс-подписи (`.caps` в `globals.css`): навигация, кнопки, пилюли,
метки, плашка героя — капс с разрядкой 6%. Мелкий серый капс из макета
(7–8px) не перенесён: у нас подписи не мельче 12px.

Трекинг текста — 1% кегля, одной строкой `letter-spacing: 0.01em`.
Интерлиньяж абзацев 1.5, заголовков 1.05–1.2.

## Цвет

```css
--canvas:    #ffffff;  /* основа страницы */
--surface:   #f5f5f5;  /* карточки и панели */
--raised:    #ebebeb;  /* ступень выше: наведение, вложенные плашки */
--line:      #dedede;  /* тонкие обводки и линии, декор */
--photo:     #e4e4e4;  /* плейсхолдер изображения */
--ink:       #141414;  /* текст, тёмные пилюли и плашки */
--body:      #3a3a3a;  /* текст абзацев: 11:1 на белом */
--muted:     #666666;  /* второстепенный текст, обводки полей: 4.8:1 на --raised */
--gold:      #ecd18a;  /* акцент-заливка */
--gold-deep: #7d6219;  /* золото текстом и значками: 5.3:1 на --surface */
--paper:     #ffffff;  /* белые плашки на сером (платёжные логотипы) */
```

`--ink` — прежняя основа тёмной темы, `--gold` не менялось. Серые
и `--gold-deep` подобраны под порог 4.5:1 на всех трёх поверхностях.

Поверхности идут ступенями: `--canvas → --surface → --raised`.
Наведение на светлом — следующая ступень. На золоте наведение
подмешивает `--ink` 12% (нажатие 24%), на тёмной пилюле — белую
основу 12% и 24%.

Тёмная палитра (`#141414 / #1e1e1e / #2a2a2a`, вечер 08.10.2026)
заменена. Её значения остались только в `TOKEN_COLORS`
(`lib/editor/document.ts`): ими раскрашиваются старые шаблоны
редактора, где цвет записан именем токена, — открытки пользователей
не перекрашиваются вместе с сайтом.

Unbounded широкий: при кегле 52 на 390 слово «Маленький» не
помещалось в строку, поэтому мобильные заголовки мельче прежних.
Крупные десктопные кегли заданы через `clamp()` от ширины окна:
на 1280 иначе «Дизайн для каждого» не встаёт в строку.

**Размер и цвет делят одно пространство имён.** Если есть `--text-foo`
и `--color-foo`, утилита `text-foo` отдаёт цвет, а размер молча
пропадает — ошибка не всплывает ни в типах, ни в сборке, текст просто
рендерится не тем кеглем. Поэтому у ролей, рядом с которыми живёт
одноимённый цвет, размер назван иначе:

| Размер | Почему не очевидное имя |
|---|---|
| `--text-menu` | рядом был `--color-nav`, имя оставлено |
| `--text-sub` | рядом `--color-body` |
| `--text-note` | рядом был `--color-caption`, имя оставлено |
| `--text-card` | утилита `text-base` встроена в Tailwind |

Найдено 03.08.2026 после вёрстки лендинга: `text-body` и `text-caption`
стояли в пяти местах как размер, а отдавали цвет. Заодно перепутанными
оказались десктопные кегли подписи подвала, пунктов списка в карточке
FAQ и подписи CTA. Проверять такое нужно в собранном CSS: `.text-body`
там должен быть `font-size`, а не `color`.

## Геометрия

```css
/* Радиусы — три ступени */
--radius-inner:   12px;  /* 16 на десктопе: поле ввода, плашка, картинка внутри карточки */
--radius-card:    20px;  /* 24 на десктопе: карточка */
--radius-panel:   24px;  /* 32 на десктопе: панель секции, герой, CTA */
/* кнопки, пилюли, стрелки, соцсети — rounded-full */
```

Картинка внутри карточки не прилегает к краю: карточка даёт поле
8 / 10px, у картинки свой `--radius-inner`.

Обводки только 1px (2px — фокус и выбранная игра):
- `--line` — пилюли, стрелка «назад», соцсети, карточка-рамка в FAQ,
  CTA, плашка героя, разделители; наведение проявляет до `--muted`
- `--ink` — стрелка «дальше», круг на картинке шаблона
- `--muted` — поля ввода и зона загрузки фото (граница поля обязана
  давать 3:1), пунктирный круг в «что внутри»
- 2px `--gold` — выбранная игра в конструкторе

Теней нет: ничего полупрозрачного. Белое на белом отделяет обводка `--line`.

Декор нарисован кодом (`components/site/Ornament.tsx`): «солнце»
из 13 лучей над чертой и три золотых кружка внахлёст.

## Точки перелома

Нарисованы ровно два состояния: 390 и 1920. Поэтому:

- **База — мобильная.** Вёрстка начинается с 390 и растёт.
- **Десктопная раскладка включается с 1280px.** Боковое поле 80px,
  контент до 1760px, расстояния в шапке интерполируются до 1920,
  см. «Сетка».
- **Промежуток 768–1279 в макете не нарисован.** Пока туда ставим
  мобильную раскладку с увеличенными полями. Отдельные планшетные
  фреймы — отдельная задача для дизайна.

## Карусели — важное отличие мобильной версии

На главной с 08.10.2026 ленты «что внутри» и «больше, чем просто
открытка» остаются лентами и на десктопе, см. «Раскладка главной».
Пилюли поводов в FAQ заменены счётчиком.

На мобильном три ряда шире экрана и в макете обрезаны краем фрейма:

1. Пилюли «Признаться в любви / Друг за границей / …»
2. Карточки «Что спрятать внутри» (4 штуки)
3. Карточки «Больше, чем просто открытка» (4 штуки)

Это горизонтальные карусели, прокручиваемые пальцем. Требования:
- `overflow-x: auto`, скроллбар скрыт
- инерционная прокрутка на iOS
- отступ справа равен боковому полю, чтобы последняя карточка
  не липла к краю
- карточка не сжимается: `flex: none`
- виден край следующей карточки — это подсказка, что ряд прокручивается

На десктопе те же ряды помещаются целиком и каруселями не являются.

## Работа с изображениями

Фото пользователя — серый плейсхолдер `--photo` в макете. В реальности
приходит любое изображение, поэтому:

- Текст никогда не лежит на голом фото. Только на подложке.
- Обрезка с учётом лица, не по центру.
- Плейсхолдер до загрузки — сплошной `--photo`, без анимированного скелетона.

## Анимация сборки открытки

С 08.10.2026, по мотивам анимированных шаблонов SUPA (supa.ru):
каждая стадия открытки собирается из слоёв, которые влетают по
очереди. Разобрано покадрово по их демо-ролику, код свой.

- слой стартует увеличенным в 1.6 раза, повёрнутым на −25°
  и прозрачным, за 700 мс встаёт на место, кривая
  `cubic-bezier(0.2, 0.8, 0.2, 1)`
- очередь — `--i` у слоя, шаг 160 мс. Фон не влетает, он холст
- класс `.assemble-layer` в `globals.css`; анимация на обёртке слоя,
  чтобы не затереть собственный наклон рамок и наклеек
- стадия монтируется заново — анимация проигрывается заново
- `prefers-reduced-motion: reduce` — анимации нет, всё сразу на месте
- контейнер стадии обрезает по горизонтали (`overflow-x: clip`),
  с полем 4px под обводку фокуса — иначе увеличенные слои на миг
  расширяли бы страницу

Обложка «С днём рождения!» — холст 3 : 4, не шире 560px: фон
`gifts.jpg`, заголовок на золотой плашке под −3°, до трёх фото автора
в белых рамках-полароидах (наклон от зерна открытки, ±2° к базовому),
наклейки Noto по краям. Нет фото — в рамках торт и шары из шаблона.
Обращение автора — на плашке `--surface` под холстом: его длина
неизвестна, а холст фиксированный.

## Панель мобильного меню

Бургер в макете нарисован, панель — нет. Спроектирована от токенов:

- панель раскрывается в потоке под шапкой и сдвигает содержимое вниз,
  а не накрывает его. Так не нужен ни оверлей, ни блокировка прокрутки,
  ни ловушка фокуса — экран остаётся одним документом
- ширина во весь экран, поля равны боковому полю сетки
- пункты разделены линией 1px `--line`, высота строки 44, текст капсом
- ниже пунктов — главная кнопка «Создать открытку» во всю ширину
- закрывается по Esc с возвратом фокуса на бургер, по нажатию вне
  шапки и по переходу по ссылке
- у бургера `aria-expanded`, у панели — свой `id`

На десктопе панели нет: с 1280px навигация видна целиком.

## Шапка прилипает к экрану

С 08.10.2026 шапка на всех страницах и ширинах `position: sticky`
сверху (решение пользователя, на телефоне тоже — не прячется при
прокрутке). Фон сплошной `--canvas`. Пока страница наверху, линии
нет; прокрутили — снизу появляется линия 1px `--line`.

- высота — токены `--spacing-header` 64 / `--spacing-header-d` 88
- `html { scroll-padding-top }` = высота шапки + 16px: прокрутка
  к якорю и к элементу в фокусе не прячет его под шапку
- мобильная панель меню раскрывается внутри шапки; на 360×640 она
  кончается на 336px и помещается. Фокус ушёл из шапки — панель
  закрывается, иначе она накрыла бы элемент в фокусе

## Экран получателя

Открытки в макете нет ни одного фрейма. Раскладка спроектирована
от токенов 05.08.2026:

- колонка по центру, не шире 900px на десктопе. Открытка — не полоса
  во всю ширину: её смотрят с телефона, и на 1920 растянутая на 1760px
  фотография перестаёт быть открыткой
- три стадии по очереди, движение только вперёд: обложка → игра →
  финал. У получателя нет «назад», он проходит открытку один раз
- **обложка** — фотография автора во всю ширину карточки (240px
  на мобильном, 420px на десктопе, `object-fit: cover`), под ней
  на подложке `--surface` обращение кеглем H3 и главная кнопка «Начать».
  Текст на голом фото не лежит нигде, см. «Работа с изображениями»
- **игра** — подсказка механики кеглем H3, под ней место игры:
  сплошной `--photo` без обводки, 300px на мобильном, 460px
  на десктопе. Игрового модуля пока нет, и картинки-обманки здесь
  тоже нет
- **финал** — карточка `--surface` с сюрпризом и подписью автора. Пустая
  карточка не показывается вовсе
- карточки обложки и финала: без обводки, `--surface`, радиус 20/24,
  внутренние поля 24/28 на мобильном и 54/40 на десктопе — те же,
  что у карточек «что внутри»
- фокус переезжает на новую стадию: кнопка, которую нажали, уходит
  вместе с прошлой стадией

Превью в конструкторе — этот же экран, и раскрывается он так же, как
панель меню: занимает место шага, а не накрывает страницу слоем.
Ни оверлея, ни блокировки прокрутки, ни ловушки фокуса.

## Состояния пилюль

Пилюля с обводкой `--line`, текст капсом. Высота 33px на мобильном
(до 44 добирает невидимое поле) и 40px на десктопе.

| | |
|---|---|
| Выбранная | заливка `--ink`, текст `--canvas` |
| Обычная | обводка `--line`, текст `--body` |
| Наведение | обводка `--muted`, текст `--ink` |
| Нажатие | заливка `--raised`, текст `--ink` |

- **Фокус** — общий из `globals.css`: 2px `--ink`, смещение 2px.
- **Выключенного состояния у пилюль не бывает.**

Выбранная пилюля подтягивается в видимую часть карусели, когда её
выбрали с клавиатуры. Плавность прокрутки спрашивается у `matchMedia`:
правило `scroll-behavior` в `globals.css` до `scrollIntoView`
не дотягивается.

Пилюля, подпись капсом, за ней стрелка «↗» — `components/Button.tsx`.

## Доступность

- Контраст текста (WCAG, светлая тема, посчитано 08.10.2026):
  `--muted` на белом 5.7:1, на `--surface` 5.3:1, на `--raised` 4.8:1;
  `--body` на `--surface` 10.4:1, на `--photo` 8.9:1;
  `--ink` на `--gold` 12.3:1; `--gold` на `--ink` 12.3:1;
  `--gold-deep` на белом 5.8:1, на `--surface` 5.3:1.
  Текст `--muted` на `--photo` не класть — 4.5 впритык.
- Декоративные номера, «солнце», кружки и круги внахлёст скрыты
  от скринридера.
- Огромный заголовок каталога разведён на две строки визуально,
  а для скринридера лежит целиком в `h2.sr-only`.
- Область нажатия минимум 44×44. Пилюли на мобильном 33px — невидимое
  поле до 44. Пункты меню шапки не уже 44px.
- Фокус: обводка 2px `--ink` (тёмная), смещение 2px — одна на светлом
  и на золоте. Класс `.on-light` снят вместе с тёмной темой.
- Ничего не сообщается только цветом.

## Цвета и шрифты содержимого открытки (08.10.2026)

Правило «только токены» — про **интерфейс сайта**: кнопки, панели,
текст страниц. Цвета и шрифты, которые пользователь выбирает для
своей открытки в редакторе `/editor`, — это его данные, а не наше
оформление. Решение пользователя от 08.10.2026: «большая палитра
и свой цвет».

- Палитра — `lib/editor/palette.ts`: девять тонов по пять ступеней,
  45 цветов. В свёрнутом виде — двенадцать основных. Плюс системный
  выбор любого цвета и ряд из восьми недавних.
- В шаблоне цвет хранится как `#rrggbb`. Имена токенов (`gold`,
  `paper`…) тоже допустимы — ими написаны шаблоны версии 1, такие
  цвета перекрашиваются вместе с сайтом.
- Кружки палитры и образцы шрифтов в списке рисуются инлайном
  (`style`) — это единственное место, где цвет и шрифт в разметке
  не из токенов. Рамки, подписи и состояния вокруг них — токены.
- Шрифты — `lib/editor/fonts.ts`: двадцать Google Fonts под OFL,
  все с кириллицей. Раздаются со своего домена, грузятся только
  на `/editor` и только когда их выбрали (`preload: false`).
- Стикеры (`public/assets/stickers`, 08.10.2026) — тоже содержимое
  открытки: рисованные по мотивам `design/пример анимации и дизайна.MP4`
  (`scripts/draw-stickers.py`) и Noto Emoji (`pnpm stickers:fetch`).
  Шаблоны редактора (`lib/editor/templates.ts`) собраны из них же,
  цвета шаблонов — hex, как у пользователя.
