# Дизайн-система «Открыточка»

Источник правды по визуалу.

С 08.10.2026 **стиль** — цвет, радиусы, обводки, кнопки, пилюли —
взят из `design/главная.jpg` и действует на весь сайт. Кегли, сетка
и раскладка внутренних страниц по-прежнему из макетов Figma
(десктоп `324:246`, мобильный `341:607`, эталоны `design/desktop.html`
и `design/mobile.html`) — но **цвет и обводки в эталонах устарели**,
сверять с ними можно только раскладку.

Если задача требует отступить от документа — сначала меняется документ.

## Характер

Мягкий и монохромный, как `design/главная.jpg`. Светло-серая основа,
на ней белые скруглённые панели и карточки, тёмные блоки почти
чёрные. **Обводок нет** — границы держатся сменой заливки. Крупная
плотная типографика, крупные тонкие цифры.

Ничего полупрозрачного, никаких размытий и градиентов. Стеклянная
мини-карточка из макета у нас непрозрачная, `--dark-2`.

Правило: **розовый `#c9356f` — точечный акцент.** Он есть только у:
- кружка со стрелкой в главной кнопке
- выбранной пилюли
- галочек и маркеров списков, прогресса конструктора, ошибок и ссылок
  в открытке

Заливок секций, подложек заголовков и розовых наведений больше нет.

## Шрифты

Оба с полной кириллицей и свободной лицензией — проверено.

```css
--font-display: 'Montserrat Alternates';  /* 400, 500, 600, 700 */
--font-ui:      'Inter';                  /* 300, 400, 500 */
```

Montserrat Alternates — **только заголовки** (H1–H3, заголовки
карточек) и логотип. Начертание SemiBold, трекинг −2%
(`tracking-tight`). Решение 08.10.2026: макет главной целиком на
гротеске, но характерный шрифт в заголовках оставлен.

Inter — всё остальное: абзацы, кнопки, навигация, пилюли, подписи,
поля ввода. Он же по умолчанию на `body`. Крупные цифры (номера
этапов, номер в карточке «что внутри», 404) — Inter Light.

Трекинг текста — 1% кегля, одной строкой `letter-spacing: 0.01em`.
Интерлиньяж абзацев 1.4, заголовков 1.15.

## Цвет

```css
--pink:    #c9356f;  /* точечный акцент, см. «Характер» */
--canvas:  #f2f2f2;  /* основа страницы */
--white:   #ffffff;  /* панели и карточки */
--line:    #e2e2e2;  /* тонкие линии, наведение на светлом */
--dark:    #161616;  /* тёмные блоки: герой, CTA, главная кнопка */
--dark-2:  #262626;  /* поверхность на тёмном, наведение тёмной кнопки */
--ink:     #111111;  /* основной текст */
--body:    #4a4a4a;  /* текст абзацев и карточек */
--muted:   #6a6a6a;  /* второстепенный текст, обводки полей ввода */
--photo:   #c8c8c8;  /* плейсхолдер изображения */
```

Основа и серые сняты пипеткой с `design/главная.jpg`. Серый текст
макета (`~#8f8f8f`) порог 4.5:1 не проходит ни на белом, ни на основе,
поэтому `--muted` затемнён до `#6a6a6a`.

Поверхности чередуются ступенью: на основе лежит белое, на белой
панели — цвета основы (пилюли, карточки шаблонов в каталоге главной).
Наведение — следующая ступень: `--white → --canvas → --line`,
на тёмном `--dark → --dark-2`.

Удалены 08.10.2026: `--pink-tint`, `--pink-card`, `--dark-badge`,
`--nav`, `--btn-ghost`, `--muted-2`, `--caption`.

Мобильный H1 использует интерлиньяж 1.1, а не 1.15 — иначе пять строк
не помещаются в первый экран. Это не опечатка, так в макете.

Первых трёх ролей в исходной таблице не было: значения сняты с макетов
при вёрстке шапки и героя.

**Размер и цвет делят одно пространство имён.** Если есть `--text-foo`
и `--color-foo`, утилита `text-foo` отдаёт цвет, а размер молча
пропадает — ошибка не всплывает ни в типах, ни в сборке, текст просто
рендерится не тем кеглем. Поэтому у ролей, рядом с которыми живёт
одноимённый цвет, размер назван иначе:

| Размер | Почему не очевидное имя |
|---|---|
| `--text-menu` | рядом был `--color-nav`, имя оставлено |
| `--text-sub` | рядом `--color-body` |
| `--text-note` | рядом был `--color-caption`, имя оставлено |
| `--text-card` | утилита `text-base` встроена в Tailwind |

Найдено 03.08.2026 после вёрстки лендинга: `text-body` и `text-caption`
стояли в пяти местах как размер, а отдавали цвет. Заодно перепутанными
оказались десктопные кегли подписи подвала, пунктов списка в карточке
FAQ и подписи CTA. Проверять такое нужно в собранном CSS: `.text-body`
там должен быть `font-size`, а не `color`.

## Геометрия

```css
/* Радиусы — три ступени, как в design/главная.jpg */
--radius-inner:   12px;  /* 16 на десктопе: поле ввода, плашка, картинка внутри карточки */
--radius-card:    20px;  /* 24 на десктопе: карточка */
--radius-panel:   24px;  /* 32 на десктопе: панель секции, герой, CTA */
/* кнопки, пилюли, стрелки, соцсети — rounded-full */
```

Картинка внутри карточки не прилегает к краю: карточка даёт поле
8 / 10px, у картинки свой `--radius-inner`. Так в макете.

**Обводок у карточек и панелей нет.** Обводка 1px остаётся только там,
где без неё элемент теряется:
- `--line` — вторичная кнопка, кнопка «назад», соцсети, активный номер
  счётчика, платёжные плашки, разделители
- `--muted` — поля ввода и зона загрузки фото: граница поля обязана
  давать 3:1, `--line` этого не даёт
- 2px `--pink` — выбранная игра в конструкторе

Тень одна — наведение на карточку шаблона:
```css
--shadow-card: 0 8px 24px 0 rgba(17,17,17,0.08);
```

## Сетка

| | Десктоп | Мобильный |
|---|---|---|
| Ширина макета | 1920 | 390 |
| Боковое поле | 150 | 20 |
| Ширина контента | 1620 | 350 |
| Колонок в сетке карточек | 4 | 1 |
| Шаг между карточками | 20 | 15–25 |

Боковое поле между 1280 и 1920 не прыгает, а растёт линейно: 40px
на 1280 и макетные 150px на 1920. Иначе на 1280 остаётся 980px
контента и десктопная шапка в них не помещается. Тем же правилом
текут расстояния в шапке: от логотипа до первого пункта 40 → 264,
шаг между пунктами 40 → 110. На 1920 всё совпадает с макетом.

## Точки перелома

Нарисованы ровно два состояния: 390 и 1920. Поэтому:

- **База — мобильная.** Вёрстка начинается с 390 и растёт.
- **Десктопная раскладка включается с 1280px.** Контент центрируется,
  максимум 1620px, боковое поле и расстояния в шапке интерполируются
  до 1920, см. «Сетка».
- **Промежуток 768–1279 в макете не нарисован.** Пока туда ставим
  мобильную раскладку с увеличенными полями. Отдельные планшетные
  фреймы — отдельная задача для дизайна.

## Карусели — важное отличие мобильной версии

На главной с 08.10.2026 ленты «что внутри» и «больше, чем просто
открытка» остаются лентами и на десктопе, см. «Раскладка главной».
Пилюли поводов в FAQ заменены счётчиком.

На мобильном три ряда шире экрана и в макете обрезаны краем фрейма:

1. Пилюли «Признаться в любви / Друг за границей / …»
2. Карточки «Что спрятать внутри» (4 штуки)
3. Карточки «Больше, чем просто открытка» (4 штуки)

Это горизонтальные карусели, прокручиваемые пальцем. Требования:
- `overflow-x: auto`, скроллбар скрыт
- инерционная прокрутка на iOS
- отступ справа равен боковому полю, чтобы последняя карточка
  не липла к краю
- карточка не сжимается: `flex: none`
- виден край следующей карточки — это подсказка, что ряд прокручивается

На десктопе те же ряды помещаются целиком и каруселями не являются.

## Раскладка главной

С 08.10.2026 структура главной взята из `design/главная.jpg`
(чужой макет, нарисован только десктоп). Сначала перенесены блоки
и их порядок, в тот же день — и стиль, на весь сайт (см. «Характер»).
Не перенесены: фото, стекло, гротеск в заголовках, метки «/About»
над заголовками — для них в словаре нет текстов. Названия и тексты
секций наши.

| Блок макета | Наша секция | Как переложено |
|---|---|---|
| Тёмная карточка с меню, H1 и мини-карточкой | Герой | Шапка — верх карточки (`Header tone="hero"`), секция — низ. Фото нет, фон `--dark`. Подзаголовок героя — в мини-карточке `--dark-2` справа внизу, соцсети — в вырезе левого нижнего угла цвета основы, название продукта водяным знаком `--dark-2` по нижнему краю (с 1280) |
| Текст слева, лента карточек справа | «Что спрятать внутри», «Больше, чем просто открытка» | Счётчик `01 ——— 02 03 04`, заголовок прижат к низу колонки, стрелки под лентой. Белые карточки, у «что внутри» крупный тонкий номер в углу. На десктопе лента остаётся лентой |
| Белая панель с текстом по центру | Каталог | Белая панель, заголовок и подводка `--muted` по центру, ниже фильтры и сетка — на месте видео и отзыва |
| Три полосы с цифрами | Три этапа | Белые полосы, слева заголовок и текст, справа номер этапа кеглем H1, Inter Light |
| Панель со счётчиком + большая картинка | FAQ | Слева панель: счётчик-вкладки, название повода, заголовок, стрелки. Справа — тёмная панель с белой карточкой ответа |
| Тёмный CTA | CTA | Выше и вплотную к подвалу |
| Строка подвала | Подвал | Наполнение наше, вид светлый: название и описание, навигация строкой, под линией оплата и соцсети |

Порядок: герой → что внутри → каталог → этапы → FAQ → преимущества → CTA.

Решения, которых в макете нет:

- **Мобильный** — каждый блок складывается в колонку. Карточка героя
  до 768px идёт во всю ширину экрана: иначе H1 52px теряет 40px
  и слова вылезают за край.
- **Колонки на десктопе** — 5 : 7, шаг 40px (ленты), 20px (FAQ).
- **Счётчик** — номер в кружке 44px. Активный: обводка 1px `--line`,
  заливка `--white`, за ним линия 1px `--muted` до остальных номеров.
  Неактивный: курсив `--muted`, наведение — `--ink`, нажатие —
  заливка `--line`.
- **Стрелки** — круг 44px. «Назад»: белая с обводкой `--line`,
  наведение `--canvas`; «дальше»: `--dark`, наведение `--dark-2`.
  Крайнее положение — иконка `--photo` (у «дальше» и заливка `--line`),
  через `aria-disabled`, чтобы фокус не слетал. Стрелки ходят по номерам, а не по краю ленты.
- **Соцсети** — белые кружки 44px с обводкой `--line` и иконкой
  `--ink`, наведение `--canvas`.
- **Панель внутри полосы** (`.inset-panel`) держит своё поле
  в `--shell-pad`: 20px, с 1280 растёт до 120 на 1920. Ленты внутри
  вырываются к краям панели.
- **Навигация в карточке героя** на десктопе: отступ от логотипа
  16 → 200, шаг 16 → 90 между 1280 и 1920. Макетные 264 / 110
  в карточку не помещаются.

Эталоны `design/mobile.html` и `design/desktop.html` для главной больше
не совпадают с кодом. Для остальных страниц они в силе.

## Работа с изображениями

Фото пользователя — серый плейсхолдер `--photo` в макете. В реальности
приходит любое изображение, поэтому:

- Текст никогда не лежит на голом фото. Только на подложке.
- Обрезка с учётом лица, не по центру.
- Плейсхолдер до загрузки — сплошной `--photo`, без анимированного скелетона.

## Панель мобильного меню

Бургер в макете нарисован, панель — нет. Спроектирована от токенов:

- панель раскрывается в потоке под шапкой и сдвигает содержимое вниз,
  а не накрывает его. Так не нужен ни оверлей, ни блокировка прокрутки,
  ни ловушка фокуса — экран остаётся одним документом
- ширина во весь экран, поля равны боковому полю сетки
- пункты разделены обводкой 1px цветом `--muted`, высота строки 44
- ниже пунктов — главная кнопка «Создать открытку» во всю ширину
- закрывается по Esc с возвратом фокуса на бургер, по нажатию вне
  шапки и по переходу по ссылке
- у бургера `aria-expanded`, у панели — свой `id`

На десктопе панели нет: с 1280px навигация видна целиком.

## Экран получателя

Открытки в макете нет ни одного фрейма. Раскладка спроектирована
от токенов 05.08.2026:

- колонка по центру, не шире 900px на десктопе. Открытка — не полоса
  во всю ширину: её смотрят с телефона, и на 1920 растянутая на 1620px
  фотография перестаёт быть открыткой
- три стадии по очереди, движение только вперёд: обложка → игра →
  финал. У получателя нет «назад», он проходит открытку один раз
- **обложка** — фотография автора во всю ширину карточки (240px
  на мобильном, 420px на десктопе, `object-fit: cover`), под ней
  на белой подложке обращение кеглем H3 и главная кнопка «Начать».
  Текст на голом фото не лежит нигде, см. «Работа с изображениями»
- **игра** — подсказка механики кеглем H3, под ней место игры:
  сплошной `--photo` с обводкой 2px, 300px на мобильном, 460px
  на десктопе. Игрового модуля пока нет, и картинки-обманки здесь
  тоже нет
- **финал** — белая карточка с сюрпризом и подписью автора. Пустая
  карточка не показывается вовсе
- карточки обложки и финала: обводка 2px `--ink`, радиус 20/30,
  внутренние поля 24/28 на мобильном и 54/40 на десктопе — те же,
  что у карточек «что внутри»
- фокус переезжает на новую стадию: кнопка, которую нажали, уходит
  вместе с прошлой стадией

Превью в конструкторе — этот же экран, и раскрывается он так же, как
панель меню: занимает место шага, а не накрывает страницу слоем.
Ни оверлея, ни блокировки прокрутки, ни ловушки фокуса.

## Состояния пилюль

Пилюля без обводки. Высота 33px на мобильном (до 44 добирает
невидимое поле) и 44px на десктопе.

| | На основе (`canvas`) | На белой панели (`white`) |
|---|---|---|
| Выбранная | заливка `--pink`, текст `--white` | то же |
| Обычная | заливка `--white`, текст `--body` | заливка `--canvas`, текст `--body` |
| Наведение | текст `--ink` | заливка `--line`, текст `--ink` |
| Нажатие | заливка `--line`, текст `--ink` | то же |

- **Наведение и нажатие на выбранную** — розовый темнеет подмешиванием
  чёрного, 90% и 80%.
- **Фокус** — общий из `globals.css`: 2px `--ink`, смещение 2px.
- **Выключенного состояния у пилюль не бывает.**

Выбранная пилюля подтягивается в видимую часть карусели, когда её
выбрали с клавиатуры. Плавность прокрутки спрашивается у `matchMedia`:
правило `scroll-behavior` в `globals.css` до `scrollIntoView`
не дотягивается.

## Кнопки

Пилюля, подпись слева, справа розовый кружок со стрелкой —
`components/Button.tsx`. Высота 52 / 64, на мобильном во всю ширину,
на десктопе по содержимому.

| | Тон `dark` (на светлом) | Тон `light` (на тёмном) |
|---|---|---|
| Обычная | `--dark`, текст `--white` | `--white`, текст `--ink` |
| Наведение | `--dark-2` | `--canvas` |
| Нажатие | `--ink` | `--line` |
| Выключенная | `--line`, текст и кружок `--muted` | — |
| Загрузка | как обычная, в кружке спиннер | — |

Вторичная (`GhostButton`) — пилюля без заливки с обводкой `--line`,
наведение `--canvas`. Стрелки лент: «назад» белая с обводкой `--line`,
«дальше» `--dark`; в крайнем положении иконка гаснет до `--photo`.

## Доступность

- Контраст текста (WCAG, посчитано 08.10.2026):
  `--muted` на `--canvas` 4.84:1, на белом 5.41:1;
  `--body` на любой светлой заливке больше 7:1;
  `--photo` на `--dark` больше 10:1; белый на `--pink` 4.97:1.
  Светлее `--muted` текст не брать.
- Декоративные крупные цифры (`--line` на белом, водяной знак
  `--dark-2` на `--dark`) скрыты от скринридера и порог не держат —
  это не текст.
- Область нажатия минимум 44×44. Пилюли на мобильном 33px — невидимое
  поле до 44.
- Фокус: обводка 2px цветом `--ink`, смещение 2px. На тёмных блоках — белая.
- Ничего не сообщается только цветом.
