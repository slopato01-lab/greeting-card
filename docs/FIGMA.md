Эталонная вёрстка обоих фреймов: `design/desktop.html`, `design/mobile.html`.
Это статические копии для сверки «попиксельно», а не продакшн-код.
Продакшн собирается из них в единый адаптивный компонент.

## Порядок сборки страницы

1. Взять `design/mobile.html` как базу — мобильный первым.
2. Наложить десктопную раскладку из `design/desktop.html` через
   медиазапрос от 1280px.
3. Абсолютное позиционирование заменить на поток: секции идут одна
   за другой, координаты `top` из эталона нужны только для проверки
   порядка и вертикальных отступов, а не для копирования в код.
4. Сверять результат с эталоном в браузере рядом, окно в окно.

Абсолютные координаты в эталонах — следствие того, что во фрейме
нет Auto Layout. Тащить их в продакшн нельзя: русский текст длиннее
макетного, имена бывают в три слова, и всё поедет.

## Ассеты

**Внимание: ссылки в эталонных HTML ведут на временное хранилище
Figma и перестанут работать примерно через неделю после экспорта.**
Их нужно заменить на локальные файлы в `public/assets/` до того,
как это станет проблемой.

Все иконки — из открытых наборов Iconify, забираются по имени
навсегда:

| Где используется | Имя в Iconify |
|---|---|
| Сертификат | `fluent-color:gift-card-16` |
| Признание | `fluent-emoji-flat:e-mail` |
| Перевод | `noto:money-bag` |
| Билет | `noto-v1:ticket` |
| Галочки в карточках преимуществ | `hugeicons:tick-04` |
| Instagram | `line-md:instagram` |
| Twitter | `line-md:twitter` |
| Facebook (внутри розового круга) | `ri:facebook-fill` |
| Бургер-меню (мобильный) | `solar:hamburger-menu-outline` |
| Декор в карточке FAQ | `game-icons:path-distance` |
| Декор-планета в герое (десктоп) | `pepicons-print:planet-ring-circle` |
| Маркер списка | простой круг, рисуется CSS |

Разделительные линии в шапке и подвале — обычные `<div>` с фоном,
не картинки.

## Платёжные логотипы — переделать

В обоих макетах шесть плашек вырезают куски **одного PNG-спрайта**
процентными сдвигами. Так жить нельзя: при любой замене спрайта
всё съедет, и на ретине это мыло.

Нужно: шесть отдельных SVG (Visa, Mastercard, Мир, Белкарт, Apple Pay,
Samsung Pay — уточнить состав), каждый как самостоятельный файл.
Логотипы платёжных систем — товарные знаки, использовать их можно
по гайдлайнам платёжного провайдера, а не произвольно.

## Опечатки в макете — исправить в текстах

Найдены при переносе, в эталонах оставлены как в оригинале:

| Где | В макете | Должно быть |
|---|---|---|
| Этап 2 | «Имя получаетля» | получателя |
| Дизайн для каждого случая | «короче топововые» | фраза явно черновая, переписать |
| Интерактивность | «новые эиоции» | эмоции |
| Пилюля фильтра | «Поделится новостью?» | Поделиться |
| Мобильный CTA | «Готовы сделать кому-то день, так готовы или нет, отвечай?» | текст-заглушка, переписать |
| Карточки шаблонов | все восемь подписаны «Для второй половинки» | нужны разные названия |
| Карточки преимуществ | три из четырёх с одинаковым текстом | нужны разные |
| Этапы 1 и 3 | одинаковый текст про сертификат | этап 1 и 3 описывают не то, что в заголовке |

Правки вносятся в `docs/PRODUCT.md`, раздел «Тексты интерфейса»,
и только оттуда попадают в код.

## Чего в макетах ещё нет

- планшетная раскладка (768–1279)
- раскрытое мобильное меню
- состояния кнопок и пилюль: hover, active, focus, disabled
- состояния загрузки, ошибки, пустоты
- содержимое карточек шаблонов и превью в блоке преимуществ
- страницы: FAQ, «Как это работает», каталог, конструктор, плеер открытки
